# SourceRx

Public website: https://zhangjas123-ops.github.io/sourcerx/

Free educational research prototype for Team 39. Explore source-linked drug records, clinical trials and organizations, compare product records and request a bounded Gemini brief.

This repository contains the public browser build. API credentials are kept on the server and are not included in these files. The site requires no visitor login. AI briefs are available to adults in the United States within free usage limits.
